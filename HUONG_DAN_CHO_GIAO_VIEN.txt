--------------------------------------------------------------------------------
🎬 TÍNH NĂNG 1: TẠO VIDEO KHỞI ĐỘNG BÀI HỌC VỚI VEO 3
--------------------------------------------------------------------------------
1. Thầy/Cô gõ tin nhắn:
   "Tôi muốn tạo kịch bản video mở đầu bài học"

2. Trợ lý AI sẽ gửi lại một biểu mẫu điền thông tin ngắn gọn:
   - Môn học, Lớp, Tên bài, Trọng tâm cần tò mò.
   - Chọn nhân vật: Thầy giáo chững chạc (~35t) / Thầy giáo trẻ (~28t) / Cô giáo trẻ (~25t).
   - Thời lượng: 60s (6 clip) / 70s (7 clip) / 80s (8 clip).

3. Sau khi Thầy/Cô điền thông tin:
   - AI sẽ gợi ý 3-5 ý tưởng kịch bản hấp dẫn kèm bảng so sánh.
   - Thầy/Cô chọn 1 ý tưởng ưng ý.
   - AI sẽ xuất trọn bộ Prompt Veo 3 từng clip đóng gói trong đúng 1 khung code duy nhất.
   - Thầy/Cô chỉ cần bấm nút "Copy" trên khung code rồi dán thẳng vào Veo 3 để tạo video!

4. Ghép video: Dùng CapCut import các clip 10s, chèn chữ tiếng Việt đè lên và thêm nhạc nền.


--------------------------------------------------------------------------------
🎓 TÍNH NĂNG 2: SOẠN SLIDE BÀI GIẢNG POWERPOINT (PPTX) CHUẨN SƯ PHẠM
--------------------------------------------------------------------------------
1. Soạn slide từ file Giáo án Word (.docx) hoặc Sách giáo khoa (.pdf):
   - Thầy/Cô kéo thả file Word giáo án hoặc PDF sách giáo khoa vào khung chat.
   - Nhắn tin:
     "Soạn cho tôi bài giảng slide PPTX chuẩn 3 bước từ giáo án này"
     hoặc:
     "Làm slide bài giảng KHTN 6 chuẩn sư phạm từ file SGK này giúp tôi"

2. Tiến trình làm việc:
   - AI tự động bóc tách hình ảnh phân giải gốc từ file và đọc nội dung bài học.
   - AI lập "Bảng phác thảo chi tiết từng slide (Storyboard)" gửi Thầy/Cô duyệt trước.
   - Thầy/Cô đồng ý -> AI tạo file PowerPoint (.pptx) chuẩn 16:9, font Times New Roman,
     chèn ảnh sắc nét, có câu hỏi và khung ghi nhớ chốt kiến thức.
   - AI gửi file PPTX hoàn chỉnh kèm đường dẫn mở trực tiếp.

3. Lồng tiếng AI & Xuất Video bài giảng MP4:
   - Muốn lồng tiếng: Kéo thả file PPTX vào file [ LONG_TIENG_AI.bat ]
     -> Chọn giọng đọc Cô Hoài My hoặc Thầy Nam Minh.
   - Muốn xuất video MP4: Kéo thả file PPTX vào file [ XUAT_VIDEO_TU_PPTX.bat ]
     -> Hệ thống tự động xuất video MP4 Full HD 1080p sắc nét để trình chiếu!
